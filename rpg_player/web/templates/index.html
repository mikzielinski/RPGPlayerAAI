      Pamięć ogólna sesji (context_general.json)
      
            
      
              Nieaktywna
              
              
            
      
          
      
          
      
            Trójpoziomowa pamięć bota: Teraz (ostatnia wypowiedź) →
            Okno kontekstu (ostatnie N wymian w buforze) →
            Pamięć ogólna (ten plik — skompresowane podsumowanie całej sesji, nigdy nie ginie).
            Gdy bufor osiągnie próg auto-flush, LLM automatycznie aktualizuje ten plik przed wyczyszczeniem buforu.
          
      
          
          
      
          
      
            
            
          
      
        
      

        
      
          
      Okno kontekstu (teraz w buforze)
      
          
      
            Bieżące wypowiedzi które bot widzi przy każdej decyzji.
            Pasek postępu w zakładce Panel pokazuje wypełnienie.
          
      
          
      
        
      

        
      
          
      Teraz (ostatnia wypowiedź)
      
          
      
            Trigger decyzji bota — ostatnia zarejestrowana wypowiedź przy stole.
          
      
          
      
        
      

      
      
    
      

    
    
      
      
      

        
      
          
      Konfiguracja Discord
      

          
      
            
          
      

          
      
            
            
      Zalecane: bot przyjmuje i wysyła wiadomości tekstem przez kanał Discord. Wyłącz tylko jeśli chcesz równoległe TTS na komputerze.
      
          
      

          
      
            
            
            
      Wygeneruj/zresetuj token w Discord Developer Portal → Twoja aplikacja → Bot → Reset Token.
      
          
      

          
      
            
            
            
      Prawy klik na nazwę serwera → Kopiuj ID serwera (tryb dewelopera musi być włączony w Ustawieniach → Zaawansowane).
      
          
      

          
      
            
            
            
      Prawy klik na kanał → Kopiuj ID kanału.
      
          
      

          
      
            
            
          
      

          
      
            
          
      

          
      
            
      Jak dodać bota do serwera
      
            
        
              
      1. Idź na discord.com/developers/applications
        2. 
              
      2. Wybierz swoją aplikację → OAuth2 → URL Generator
        3. 
              
      3. Zaznacz scope: bot
        4. 
              
      4. Zaznacz uprawnienia: Read Messages, Send Messages, View Channels, Read Message History
        5. 
              
      5. Skopiuj wygenerowany URL i otwórz w przeglądarce
        6. 
              
      6. Wybierz swój serwer i kliknij Autoryzuj
        7. 
              
      7. W Bot → Privileged Gateway Intents włącz: Message Content Intent, Server Members Intent
        8.
